# v0.1.0 Initial Public Release

This is the first sanitized public release of Daily Stock Workflow.

## Included

- Daily stock-selection workflow scripts.
- LLM-assisted candidate scoring and debate modules.
- Backtesting helpers.
- Intraday dry-run execution helpers.
- Weekly review and Top5 attribution scripts.
- Bilingual README files.
- Example environment file and security notes.

## Sanitized From Public Release

- Real API keys and webhooks.
- Runtime logs and reports.
- Account, position, and execution records.
- Local absolute paths and private network addresses.
- Python caches, virtual environments, and generated outputs.

## Notes

Start with `DRY_RUN=1`. This project is research tooling and does not provide
investment advice.
