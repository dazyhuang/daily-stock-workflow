# v0.2.0 Traceable Workflow Core

This release updates the sanitized public repository to the workflow used in
July 2026 and makes the main selection path easier to inspect and resume.

## Highlights

- Every major data class now carries source, freshness, fallback, and quality metadata.
- Technical claims can be checked against a deterministic market snapshot instead of prompt prose alone.
- Knowledge rules and learned edge rules expose their evidence fields and score effects.
- Checkpoints validate the candidate universe and scoring versions before reuse.
- Model calls expose a configurable primary/fallback cascade and clearer failure attribution.
- Intraday decisions produce audit events that feed a weekly execution review.

## Public-Safety Changes

- Replaced local usernames, private IP addresses, and machine-specific paths with environment settings.
- Removed personal provider profile identifiers.
- Disabled automatic loading of the Codex desktop OAuth token; set `OPENAI_API_KEY` for OpenAI API routes.
- Runtime reports, account data, positions, trade records, keys, webhooks, and generated outputs remain excluded.

## Validation

- Python syntax compilation passed for the updated workflow modules.
- Core data-router, market-snapshot, knowledge-rule, edge-rule, checkpoint, scoring, model-cascade, intraday-review, and Top5-attribution regression suites passed.
- The 31-case resume and incremental-prefetch suite passed. Its expected network fallbacks were validated separately from the focused offline checks.
